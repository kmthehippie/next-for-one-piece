# NextForOnePiece

Spoiler-safe watch-order tracker.

## Setup

1. Create a Supabase project.
2. Enable Google auth in Supabase.
3. Run `supabase.sql` in the Supabase SQL editor.
4. Copy `.env.example` to `.env.local` and fill in the public Supabase URL and anon key.
5. Run:

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
```
